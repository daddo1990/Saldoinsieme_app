# SaldoInsieme original UI identity
- Main color #163E35 forest; action green #116C52; ivory #FAF9F4; mint #DDF4E4.
- Accent panels by category, custom abstract geometry with Flutter widgets (no external stock images).
- DM Sans via google_fonts with display typography, 18-24px rounded cards and spacious layout.
- Navigation: Esplora, Cerca, Pubblica, Profilo; create request available from home CTA.
- Stories show confirmed contributions separately from the initial target. No fake numbers or fake donors.
- Support sheet includes presets, custom amount, 5% surcharge and clear total; never preselected upsell.
- All payments disabled and labels explicitly say demo.
- Users keep their full supporting documents private. Public list shows only scrubbed narrative text and funding amounts.
- Before release, perform device screenshot checks on small and large iPhones and Android devices, visual accessibility audit, contrast and font scaling testing.
