# SaldoInsieme — Flutter App

Flutter client for SaldoInsieme Cloud. Original premium Italian UX (forest green / ivory / soft coral). No actual PSP/payment is implemented. Service fee is 5% **on top** of the chosen amount. Pledges are DEMONSTRATION ONLY; no money is transferred.

## Run
1. Install Flutter stable and clone this repository.
2. Bootstrap platform shells once: `flutter create . --project-name saldoinsieme_app --platforms=android,ios,web`
3. `flutter pub get`
4. Start cloud Laravel API.
5. Android emulator: `flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000`
6. iOS simulator: `flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000`.
7. Physical devices require a reachable and preferably HTTPS API URL.
8. Offline mode shows clearly labelled fictional preview stories only.

Features: explore/search/categories, request details, fee-transparent contribution simulation, login/register/secure session storage, create requests, upload documentary evidence for verification, your requests/history and profile. All real-money features are disabled pending PSP approval.

Platform folders (Android/iOS) are generated by the local Flutter CLI because it is not installed in this authoring environment. This is a development baseline, not a store-ready build.

## Windows workstation / local API
- In PowerShell: `flutter create . --project-name saldoinsieme_app --platforms=android,ios,web,windows`.
- For a Windows desktop preview: `flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:8000`.
- For Android emulator: `flutter run -d emulator-5554 --dart-define=API_BASE_URL=http://10.0.2.2:8000`.
- For Chrome: `flutter run -d chrome --web-port 3000 --dart-define=API_BASE_URL=http://127.0.0.1:8000`. Configure `CORS_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000` in Cloud.
- `android/app/src/debug/AndroidManifest.xml` allows unencrypted HTTP **debug builds only**. Release builds must use HTTPS.
- On Plesk, point Laravel document root to `public/`. Connect Flutter to the actual HTTPS domain with `--dart-define=API_BASE_URL=https://your-cloud.example`.
- Do not place real API secrets in Flutter dart-defines, since app binaries can be inspected.
